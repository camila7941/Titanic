Repositorio oficial del proyecto de análisis de datos e ingeniería de datos enfocado en el procesamiento, depuración y transformación del histórico conjunto de datos del Titanic (1912).

# Descripción del Proyecto
Este proyecto aborda el análisis exploratorio y la limpieza profunda de una versión ruidosa y corrupta del conjunto de datos del Titanic. A través de técnicas avanzadas de procesamiento de datos en Python, se corrigieron inconsistencias tipográficas, errores sintácticos, valores anómalos y nulos críticos con el fin de consolidar una base de datos limpia, consistente y lista para su implementación en modelos analíticos o tableros de inteligencia de negocios 
# Proceso de Limpieza y Preparación de Datos
Debido a la alta presencia de ruido y corrupción en la fuente secundaria, se implementó un pipeline robusto de preprocesamiento que contempló: Corrección Tipográfica y Distancia de Levenshtein. Estandarización de prefijos en identificadores y tiquetes ante errores de digitalización o caracteres confusos. Algoritmos de emparejamiento por similitud de texto para recuperar identificadores de pasajeros duplicados o corruptos. Tratamiento de Valores Nulos e Imputación. Limpieza de símbolos de moneda, corrección de puntos decimales desplazados por errores de codificación
